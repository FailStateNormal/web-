# 实验2：PC端网页布局——主义者测验

## 一、打开方式

在 HBuilder / HBuilderX 中选择“文件 → 打开目录”，打开本文件夹。分别打开 `index.html`、`quiz.html`、`result.html`，选择“在浏览器中运行”；也可以在文件夹中分别双击这三个 HTML 文件。

顶部栏目和面包屑仅保留静态外观，换页时直接打开对应 HTML 文件。不需要安装依赖或构建项目。

本次沿用人生哲学测试主题与深蓝、金色视觉风格。

## 二、项目文件

```text
前端实验2/
├── index.html       首页
├── quiz.html        完整20道题的静态答题页
├── result.html      结果示例页
├── css/
│   └── main.css     三个页面共用的外部样式表
└── readme.md        分工与技术说明
```


## 三、布局实现

1. **首页与内容页**：完成首页、答题页、结果示例页，文件名使用英文小写字母。
2. **PC 整体居中**：`.container` 设置 `max-width: 1120px`、`margin: 0 auto`，宽屏下左右留白一致，窄窗口下按可用宽度收缩。
3. **页面标题**：每页设置与内容对应的独立 `<title>`。
4. **统一外观**：三个页面采用相同的深蓝背景、金色强调、卡片、页眉、页脚和栏目样式。
5. **外部样式表**：三页均通过 `<link rel="stylesheet" href="css/main.css">` 引用公共样式，无页面内联样式。
6. **布局技术**：使用盒模型、Flex、Grid、相对/绝对定位、伪元素与媒体查询。装饰圆环使用 CSS 绘制，不依赖外部图片或字体服务。
7. **完整内容**：答题页包含参考源代码中的全部 20 道题和 80 个选项，依次纵向展示，无需创建 20 个独立页面。第一题保留选中状态的静态样式示例。
8. **推荐时长**：首页显示 `10 Min`，答题页同步说明推荐预留 10 分钟。

Word 中 `index-img.html`、`index-bg.html`、`index-cover.html`、`index-contain.html` 是布局方法示例，无需全部制作；本项目采用整体水平居中的方案。

Word 原要求包含站内链接。本阶段依照小组最新要求暂时移除页面跳转，保留栏目外观；最终验收如需满足站内链接要求，可在后续阶段补回。

## 四、当前实现范围

已完成静态页面、全部题目及选项、统一视觉、选中状态示例与基础窄屏适配。

暂不实现页面跳转、选项选择、上一题/下一题、答题记录、自动计分、动态结果、重新测试及数据保存。页面中不包含 JavaScript 交互逻辑。

结果页固定显示理想主义示例；45%、25%、15%、10%、5% 为演示比例，合计 100%，不代表实际答题结果。
